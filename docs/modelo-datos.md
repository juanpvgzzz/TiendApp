# Modelo de datos
`customers` representa personas identificadas; el nombre no es único. `accounts` representa visitas, admite invitado y referencia la jornada `shifts`. `account_access` concede acceso por usuario Auth. `orders` y `order_items` representan solicitudes. `deliveries` representa unidades cobrables con precio aplicado. `delivery_corrections` registra ajustes sin editar entregas. `payment_requests` y `payments` conservan el cierre. `staff` almacena roles fiables separados de metadatos del navegador. `private.link_codes` y `private.audit` quedan fuera del esquema expuesto.
